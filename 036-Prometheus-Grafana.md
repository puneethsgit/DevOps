# 🚀 Kubernetes Monitoring with Prometheus & Grafana in Minikube  

This guide provides a **step-by-step approach** to installing and configuring **Prometheus, Grafana, and Kube-State-Metrics** in a **Minikube cluster**.

---

## 📌 What is Prometheus Stack?  

The **Prometheus Stack** (also called **Kube-Prometheus-Stack**) is a **collection of monitoring tools** used to observe Kubernetes clusters efficiently. It includes:  

- **Prometheus** - A time-series database for storing metrics  
- **Alertmanager** - Handles alerts generated by Prometheus  
- **Grafana** - A visualization tool for Prometheus metrics  
- **Node Exporter** - Collects system-level metrics  
- **Kube-State-Metrics** - Provides insights into Kubernetes objects  

### 🔹 What Does "Stack" Stand For?  
The **stack** represents a **bundle of related components** that work together to provide a complete monitoring solution in Kubernetes. Instead of installing each component **individually**, we deploy the entire **stack** with Helm.

---

## 📌 What is Helm & Why Use It?  

**Helm** is a **package manager** for Kubernetes, similar to `apt` for Ubuntu or `yum` for CentOS. It simplifies application deployment by managing Kubernetes manifests.  

### 🔹 How Helm Reduces Manual Work  
✅ Automates deployment of complex applications  
✅ Eliminates the need to manually create multiple YAML files  
✅ Allows version control and easy upgrades/rollbacks  
✅ Simplifies configuration management using **values.yaml**  

Instead of manually running multiple `kubectl apply` commands, we **install and manage applications** with just a single **Helm command**.

---

## 1️⃣ Installing Prometheus & Grafana with Helm  

### 🔹 Add Helm Repo  
```sh
helm repo add prometheus-community https://prometheus-community.github.io/helm-charts
helm repo update
```

### 🔹 Install Prometheus Stack  
```sh
helm install prometheus prometheus-community/kube-prometheus-stack --namespace monitoring --create-namespace
```

### 🔹 Verify Installation  
```sh
kubectl get pods -n monitoring
```
You should see multiple pods running, including `prometheus`, `alertmanager`, and `grafana`.

---

## 2️⃣ Exposing Prometheus  

### 🔹 Patch Service to NodePort  
```sh
kubectl patch svc prometheus-kube-prometheus-prometheus -n monitoring -p '{"spec": {"type": "NodePort"}}'
```

### 🔹 Find Prometheus NodePort  
```sh
kubectl get svc -n monitoring | grep prometheus-kube-prometheus-prometheus
```
Example output:  
```
prometheus-kube-prometheus-prometheus   NodePort   XX.XXX.XX.XX   <none>   XXXX:XXXXX/TCP   10m
```
Here, `XXXXX` is the **NodePort**.

### 🔹 Access Prometheus  
```sh
minikube ip
```
Visit Prometheus in your browser:  
```
http://<MINIKUBE-IP>:<NODEPORT>
```

## 4️⃣ Retrieve Grafana Admin Password  

### 🔹 Get Admin Password  
```sh
kubectl get secret -n monitoring prometheus-grafana -o jsonpath="{.data.admin-password}" | base64 --decode ; echo
```
📌 **Default Username:** `admin`  

---

## 5️⃣ Add Prometheus as a Data Source in Grafana  

1. Open Grafana  
2. Go to **☰ Menu → Data Sources**  
3. Click **Add data source**  
4. Select **Prometheus**  
5. Enter the Prometheus URL:  
   ```
   http://<minikubeip>:<prometheus port>
   ```
6. Click **Save & Test** ✅  

---

## 6️⃣ Import Kubernetes Dashboard (ID: 3662)  

1. Open Grafana  
2. Navigate to **Dashboards → Import**  
3. Enter **ID: 3662**, click **Load**  
4. Select **Prometheus** as the data source  
5. Click **Import**  
6. 🎉 **Kubernetes dashboard is now live!**

### 🔹 Access Metrics  
```
http://<MINIKUBE-IP>:<KUBE-STATE-METRICS-NODEPORT>/metrics
```

---

## 8️⃣ Configure Prometheus to Scrape Kube-State-Metrics  

### 🔹 Edit Prometheus ConfigMap  
```sh
kubectl edit cm prometheus-kube-prometheus-prometheus -n monitoring
```

### 🔹 Add the Following Under `scrape_configs:`  
```yaml
  - job_name: 'kube-state-metrics'
    static_configs:
      - targets: ['<MINIKUBE-IP>:<KUBE-STATE-METRICS-NODEPORT>']
```
📌 **Replace `<MINIKUBE-IP>` and `<KUBE-STATE-METRICS-NODEPORT>`** with actual values.  

### 🔹 Restart Prometheus  
```sh
kubectl delete pod -n monitoring -l app.kubernetes.io/name=prometheus
```
This ensures that **Prometheus reloads the configuration**.

## 9️⃣ Troubleshooting Issues & Fixes  

### **❌ Issue 1: Prometheus Pods Stuck in Pending**  
**Solution:** Delete PVC & reinstall  
```sh
kubectl delete pvc -n monitoring --all
helm uninstall prometheus -n monitoring
helm install prometheus prometheus-community/kube-prometheus-stack --namespace monitoring
```

---

### **❌ Issue 2: Grafana "Site Can't Be Reached"**  
**Solution:** Expose Grafana  
```sh
kubectl patch svc prometheus-grafana -n monitoring -p '{"spec": {"type": "NodePort"}}'
```

---

### **❌ Issue 3: `curl` Returns 404 for Prometheus/Grafana**  
**Solution:** Check Minikube IP and NodePort  
```sh
minikube ip
kubectl get svc -n monitoring
```
Correct URL:  
```
http://<MINIKUBE-IP>:<NODEPORT>
```

---

### **❌ Issue 4: Kube-State-Metrics Not Accessible**  
**Solution:** Change service type  
```sh
kubectl patch svc prometheus-kube-state-metrics -n monitoring -p '{"spec": {"type": "NodePort"}}'
```
